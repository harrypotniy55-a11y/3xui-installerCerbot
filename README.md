
# 3X-UI SSL Installer

Автоматическая установка SSL-сертификата Let's Encrypt для панели 3X-UI с помощью Docker и Certbot.

## 🚀 Команда установки

Выполните команду на сервере от имени root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/harrypotniy55-a11y/3xui-installerCerbot/refs/heads/main/3xui-ssl-setup.sh)
```

## ⚙️ Как это работает

1. Скачивает установщик напрямую с GitHub.
2. Запускает установку без предварительного сохранения файла.
3. Запрашивает домен панели и email.
4. Устанавливает Docker, если он отсутствует.
5. Выпускает SSL-сертификат Let's Encrypt.
6. Настраивает автоматическую проверку и продление сертификата.

## 📋 Возможности

- Автоматическая установка Docker.
- Выпуск SSL-сертификата.
- Автоматическое продление сертификата.
- Ежедневная проверка срока действия в 03:17.
- Вывод путей сертификата и приватного ключа.

## 📁 Пути сертификатов

**Certificate:**
```text
/etc/letsencrypt/live/ДОМЕН/fullchain.pem
```

**Private key:**
```text
/etc/letsencrypt/live/ДОМЕН/privkey.pem
```

## Требования

- Ubuntu / Debian
- Root-доступ
- Домен, направленный на IP сервера
- Открытый порт 80
